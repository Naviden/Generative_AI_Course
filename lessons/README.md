## How to work through a lesson

1. **Read** the specific theory section linked from that step. Write down what the model represents and what its objective measures.
2. **Predict** the result before running the code. A wrong prediction is useful if you can explain why it changed.
3. **Run** only the experiment requested at that step. All commands run from the repository root with your environment active.
4. **Inspect** the named output fields and the named implementation functions. The printed numbers are measurements, not grades.
5. **Explain** what your result supports and what it cannot establish. Attempt the checkpoint before opening the answer.

Keep a [learning log](learning-log.md) in your own notes or in `runs/learning-log.md`. Record run-folder names rather than copying only a favorable number. The [output guide](../labs/outputs.md) explains the JSON structure and saved arrays.

## Schedule and scope

Lessons 01, 02 and 03 correspond to the three four-hour meetings. Their numbered steps group the existing activities; they do not add extra classroom assignments. Follow the [timed syllabus](../docs/syllabus.md) for the lesson activities and teaching sequence. The readiness step is preparation outside those meetings. Self-study readers can take longer and use the same sequence without a timetable.

**Required:** the linked theory sections, four core labs, interpretation questions and in-class assessment. **Optional:** full papers, plotting extras, historical scripts and research extensions. You do not need to repair an old notebook or train every model mentioned in the reading list.

## If you get stuck

- Missing file or package: [setup troubleshooting](../docs/setup.md#troubleshooting).
- Code runs but numbers are unclear: [output guide](../labs/outputs.md), then the interpretation section in your current lesson.
- An equation is unclear: return to the linked theory section and use the worked checkpoint.
- Execution is unavailable: use the [recorded results](../docs/validation.md), clearly label them as supplied evidence, and still complete the prediction and interpretation tasks.
