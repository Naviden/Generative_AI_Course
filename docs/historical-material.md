# Historical and optional material

[Start the numbered lessons](../lessons/README.md). None of the folders below is another required lesson. They preserve the original repository's examples and references; some are incomplete or have different dependencies. The [file-level audit](repository-audit.md) explains specific limitations.

| Folder | Topic / possible use after the core path | Status and route to current material |
|---|---|---|
| [Traditional Generative Models](../Traditional%20Generative%20Models/README.md) | Naive Bayes, HMM and GMM refreshers | Optional prerequisite illustrations; not covered by core execution tests |
| [Neural Generative Models](../Neural%20Generative%20Models/README.md) | Original VAE and GAN scripts/notebooks | Some sketches lack complete training; use Lesson 01's tested VAE for the required experiment |
| [Transformers](../Transformers/README.md) | Small historical attention calculation | Scaling and softmax were corrected; Lesson 01 provides the guided causal-attention exercise |
| [LM](../LM/README.md) | Historical BERT/GPT-2 demos and statistical LM notebook | Downloads/optional dependencies; the HMM notebook has unresolved semantic issues |
| [other](../other/README.md) | RNN classifier and sequence-to-sequence sketch | Optional comparisons, not complete generative-model lessons |
| [Books and Tutorials](../Books%20and%20Tutorials/README.md) | Inherited reference PDFs | Not required reading; third-party rights remain applicable |
| [data](../data/README.md) | Inherited `Alice.txt` | Used by archival experiments; core labs generate synthetic data |

Why keep the paths? Existing notebooks, book links and external references may use them. Adding explicit orientation and a separate numbered student path improves navigation without silently breaking those references. Do not interpret presence in the repository as certification that a historical script is correct or ready to run.
