## Before using an archived example

Read the [historical-material guide](../docs/historical-material.md) and [file-level audit](../docs/repository-audit.md). Some programs are incomplete, require separate dependencies or start long training runs. Archiving does not change their validation status. The current course uses the supported implementations in [genai_course/](../genai_course/README.md).

Relative asset paths inside a historical folder retain the same relationships. For example, GMM plotting assets remain beside their notebooks. The statistical-language-model notebook still has the previously documented bare `Alice.txt` path and HMM issues; the preserved text is now in [data/Alice.txt](data/Alice.txt). This move does not claim to repair or execute that notebook.

For old links to a file on `main`, insert `archive/` before the old topic-folder path. Links pinned to commits before this move still resolve to the earlier layout.

Third-party reference works retain their original rights; no new license or redistribution permission is implied. The archived 2023 requirements file is not the environment to install for current lessons.
